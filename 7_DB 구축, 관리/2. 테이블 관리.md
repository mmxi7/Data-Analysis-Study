# 테이블 관리

## 테이블 생성하기

### 테이블 생성 기본 구조

```sql
CREATE TABLE [IF NOT EXISTS] 테이블이름 (
    컬럼이름1 데이터타입 [제약조건] [COMMENT '컬럼설명'],
    컬럼이름2 데이터타입 [제약조건] [COMMENT '컬럼설명'],
    ...
    [PRIMARY KEY (컬럼이름)],
    [FOREIGN KEY (컬럼이름) REFERENCES 부모테이블(컬럼)],
    ...
) [DEFAULT CHARSET=문자셋] [COLLATE=콜레이션] [COMMENT='테이블설명'];
```

- 테이블 이름은 **영어 복수형**, 컬럼 이름은 **영어 단수형**으로 지정하는 것을 권장
- `IF NOT EXISTS` : 기존 테이블과 이름이 중복되지 않을 경우에만 테이블 생성
- 기본 문자셋과 콜레이션은 데이터베이스와 동일하게 설정하는 것을 권장
  - 권장 문자셋 : `utf8mb4`
  - 권장 콜레이션 : `utf8mb4_bin`
- 테이블과 각 컬럼의 용도를 파악하기 위해 `COMMENT`를 입력하는 것을 권장

<br>

## 컬럼의 데이터 타입

- **정수형**

| 데이터 타입 | 설명 | 사용 예 | 값의 종류 |
|---|---|---|---|
| `TINYINT` | 아주 작은 정수 (1바이트) | 상품 평점(1~5), 상태 코드 | -128 ~ 127 |
| `SMALLINT` | 작은 정수 (2바이트) | 재고 수량, 배송 단계 | -32,768 ~ 32,767 |
| **`INT / INTEGER`** | 일반적인 정수 (4바이트) | 회원 번호, 주문 번호, 상품 가격 | -2,147,483,648 ~ 2,147,483,647 |
| `BIGINT` | 아주 큰 정수 (8바이트) | 결제 트랜잭션 ID, 누적 포인트 | ±9경 |

- **실수형**

| 데이터 타입 | 설명 | 사용 예 | 값의 종류 |
|---|---|---|---|
| **`FLOAT`** | 소수점 이하 표현, 낮은 정밀도 | 할인율, 배송 무게 | 부동소수점 |
| `DOUBLE` | 높은 정밀도 소수 | 환율, 위도/경도 | 부동소수점 |
| `DECIMAL(p,s)` | 정확한 고정 소수점 | 환율, 위도/경도 | 고정소수점 |

- **문자열**

| 데이터 타입 | 설명 | 사용 예 | 값의 종류 |
|---|---|---|---|
| **`CHAR(n)`** | 고정 길이 문자열 | 상품 코드, 국가 코드, 우편번호 | 문자 |
| **`VARCHAR(n)`** | 가변 길이 문자열 | 회원 이름, 이메일 | 문자 |
| **`TEXT`** | 긴 텍스트 | 상품 설명, 후기 | 장문 텍스트 |
| **`ENUM`** | 고정된 선택값 중 하나 | 성별, 주문 상태 | 정해진 문자열 중 선택 |


- **날짜, 시간형**

| 데이터 타입 | 설명 | 사용 예 | 값의 종류 |
|---|---|---|---|
| **`DATE`** | 날짜만 저장 | 회원가입일, 결제일 | `YYYY-MM-DD` |
| **`DATETIME`** | 날짜와 시간 저장 | 주문 일시, 로그인 시간 | `YYYY-MM-DD HH:MM:SS` |
| **`TIME`** | 시간만 저장 | 배송 예상 시간 | `HH:MM:SS` |


- **논리형**

| 데이터 타입 | 설명 | 사용 예 | 값의 종류 |
|---|---|---|---|
| **`BOOLEAN`** | 참/거짓 표현 | 회원 활성 여부, 재고 여부 | 0(거짓), 1(참) |

## 컬럼의 제약 조건

| 제약조건 | 설명 | 효과 |
|---|---|---|
| `NOT NULL` | NULL 값 저장 금지 | 반드시 값 입력 필요 |
| `DEFAULT` | 기본값 지정 | 입력 없을 시 자동 입력 |
| `UNIQUE` | 중복 불가 | 컬럼 값 중복 방지 |
| `PRIMARY KEY` | 기본키 지정 | 테이블의 고유 식별자 |
| `AUTO_INCREMENT` | 자동 증가 값 | 새 레코드마다 자동 증가 |

### 많이 사용되는 기본값 유형

데이터 타입이 `ENUM('Y','N')`으로 되어 있을 경우 둘 중 하나의 값을 기본값으로 지정
```sql
DEFAULT 'Y' / 'N'
```

데이터 타입이 `DATETIME`으로 되어 있을 경우 자동으로 데이터 저장 시각을 저장
```sql
DEFAULT CURDATE()
```

## 테이블 삭제하기

### 테이블 삭제 구문의 기본 구조

```sql
DROP TABLE [IF EXISTS] 테이블이름;
```

- `DROP TABLE` 명령은 즉시 실행되며 복원이 불가능하므로 신중하게 수행해야 함
- `IF EXISTS` : 삭제 대상 테이블이 존재할 경우에만 명령을 실행
  - 이 옵션이 없을 경우 대상 테이블이 없다면 에러 발생
- 자신을 참조하는 자식 테이블이 있을 경우 해당 테이블을 삭제할 수 없음
  - `members` 테이블과 `books` 테이블은 `loans` 테이블이 삭제되지 않는 한 삭제 불가능

<br>

## 테이블 수정하기

### 수정 구문의 기본 구조

```sql
ALTER TABLE 테이블이름 수정작업;
```

- 테이블 수정이 빈번하게 발생할 경우 설계가 잘못된 것으로 봐야 함

| 수정 작업 유형 | 구문 구조 | loans 테이블 예시 |
|---|---|---|
| 컬럼 추가 | `ADD 컬럼명 데이터형식 [제약조건]` | `ALTER TABLE loans ADD renew_count TINYINT DEFAULT 0 COMMENT '연장 횟수';` |
| 컬럼 삭제 | `DROP COLUMN 컬럼명` | `ALTER TABLE loans DROP COLUMN notes;` |
| 컬럼 수정 | `CHANGE 기존컬럼명 새컬럼명 데이터형식` | `ALTER TABLE loans CHANGE fine_amount late_fee DECIMAL(10,2);` |
| 컬럼 속성 수정 | `MODIFY 컬럼명 새형식` | `ALTER TABLE loans MODIFY due_date DATE NOT NULL COMMENT '최종 반납일';` |
| 기본키 추가 | `ADD PRIMARY KEY (컬럼)` | `ALTER TABLE loans ADD PRIMARY KEY (id);` |
| 외래키 추가 | `ADD FOREIGN KEY (컬럼) REFERENCES 테이블(컬럼)` | `ALTER TABLE loans ADD FOREIGN KEY (staff_id) REFERENCES staff(id);` |
| 외래키 삭제 | `DROP FOREIGN KEY 참조키별칭` | `ALTER TABLE loans DROP FOREIGN KEY fk_loans_member;` |
| 테이블 이름 변경 | `RENAME TO 새이름` | `ALTER TABLE loans RENAME TO book_loans;` |
