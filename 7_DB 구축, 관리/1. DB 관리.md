# DB 관리

## DB 생성
### **생성 구문**
```sql
CREATE DATABASE [IF NOT EXISTS] DB이름
[DEFAULT CHARSET 캐릭터셋 COLLATE 콜레이션];
```

### **시스템의 기본 캐릭터 셋과 콜레이션 확인**
```sql
SHOW VARIABLES LIKE 'character_set_server';
SHOW VARIABLES LIKE 'collation_server';
```

### **캐릭터 셋과 콜레이션**
  - **캐릭터 셋** : 컴퓨터가 문자를 저장하고 표현하는 방식
    | 문자셋 | 특징 |
    |---|---|
    | `EUCKR` | 한글 표현용 (2바이트) |
    | `utf8mb3` | MySQL/MariaDB의 3바이트 UTF-8 표현 (일부 문자 누락) |
    | `utf8mb4` | 진짜 전체 유니코드 지원 (이모지 포함) ← **권장** |
    
  - **콜레이션** : 문자열의 비교, 정렬 방식 규칙
 
  <br>

## 사용자 계정 생성

### **새로운 사용자 생성**
```sql
create user '아이디'@'접근허용호스트' identified by '비밀번호';
```

### **특정 사용자에게 DB 접근 권한 부여**
```sql
grant all privileges on DB이름.* to '아이디'@'접근허용호스트';
```
> `*`는 DB에 대한 모든 권한을 부여한다는 뜻
