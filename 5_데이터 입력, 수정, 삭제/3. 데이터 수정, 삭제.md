# 데이터 수정, 삭제

### 데이터 수정: `UPDATE` 문

```sql
UPDATE ...
SET ...
[WHERE 조건]
```

> `WHERE` 절을 생략하면 모든 행이 수정되므로 주의

### 데이터 삭제: `DELETE` 문

```sql
DELETE FROM ...
[WHERE 조건]
```

> `WHERE` 절을 생략하면 모든 행이 삭제되므로 주의해야 한다.

- 데이터 삭제시 주의사항: 다른 테이블에서 참조하고 있는 부모 데이터를 삭제하려고 하면 **참조 무결성** 제약조건에 의해 삭제되지 않을 수 있다.

### 01

학번이 10101번인 학생의 전화번호를 '010-1234-5678'로 수정하세요.

```sql
UPDATE students
SET phone = '010-1234-5678'
WHERE id = 10101;
```

### 02

모든 ‘휴학’ 상태의 학생을 ‘재학’으로 변경하세요.

```sql
UPDATE students
SET status = '재직'
WHERE status = '휴학'
```

### 03

1학년 학생 중 키가 160cm 이하인 학생을 삭제하시오.  
삭제가 안될 경우 왜 삭제가 안되는지 확인하세요.

```sql
DELETE FROM students
WHERE grade = 1 AND height <= 160;
```

### 04

102번 학과의 이름을 '소프트웨어학과'로, 위치를 '공학관'으로 수정하세요.

```sql
UPDATE departments
SET dname = '소프트웨어학과', loc = '공학관'
WHERE id = 102;
```

### 05

2024년 3월 10일 이전에 수강신청한 내역을 삭제하시오.  
삭제가 안될 경우 왜 삭제가 안되는지 확인하세요.

```sql
DELETE FROM enrollments
WHERE DATE_FORMAT(enroll_date, '%Y%m%d') < '20240310';
```
