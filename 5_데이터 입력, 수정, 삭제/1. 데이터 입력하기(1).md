# 데이터 입력하기(1)

### 데이터 저장: `INSERT`

테이블에 새로운 데이터를 추가할 때 사용

```sql
INSERT INTO 테이블명 () VALUES ();
```

<br>

### 데이터 무결성

데이터의 **정확성과 일관성을 유지**하기 위한 규칙

| 구분 | 의미 | 관련 제약조건 |
|---|---|---|
| 엔티티 무결성 | 각각의 행을 고유하게 식별 | `PRIMARY KEY` |
| 도메인 무결성 | 필드에 허용되는 값의 범위를 제한 | 데이터 타입, `NOT NULL` |
| 참조 무결성 | 테이블 간의 올바른 참조 관계 유지 | `FOREIGN KEY` |

<br>

### `PRIMARY KEY`: 테이블의 각 행을 **고유하게 식별하기 위한 기본키**

- 중복된 값을 가질 수 없음
- `NULL` 값을 가질 수 없음
- 하나 이상의 필드로 구성
- 하나의 테이블에는 하나의 `PRIMARY KEY`만 존재

> 이미 존재하는 기본키 값을 다시 입력하면 오류 발생

<br>

### `AUTO_INCREMENT`: 새로운 데이터가 입력될 때 **숫자 값을 자동으로 증가시켜 저장하는 속성**

`AUTO_INCREMENT`가 설정된 필드에 `NULL`을 입력하면 다음 번호가 자동으로 생성됨

<br>

### `NULL`: **값이 존재하지 않는 상태**

`NULL`을 허용하는 필드는 직접 `NULL`을 입력하거나 생략 가능

<br>

### `NOT NULL`: **반드시 값이 입력되도록 제한하는 제약조건**

`NOT NULL`이 설정된 필드는 `NULL`을 입력하거나 생략할 수 없음

### 01

학과 테이블(departments)에 소프트웨어공학과를 새로 등록하세요. 학과 번호는 자동으로 생성되도록 하며,  
학과명은 '소프트웨어공학과', 위치는 '2호관', 전화번호는 '051-123-7890', 이메일은 'sw@myschool.ac.kr',  
설립연도는 2012, 홈페이지는 'http://sw.myschool.ac.kr'로 입력하세요.

```sql
INSERT INTO departments (dname, loc, phone, email, established, homepage)
VALUES ('소프트웨어공학과', '2호관', '051-123-7890', 'sw@myschool.ac.kr', 2012, 'http://sw.myschool.ac.kr');
```

```sql
INSERT INTO students (name, user_id, grade, idnum, birthdate, height, weight, gender, phone, status, department_id) VALUES ('박세리', 'parksl', 2, '051017-4000000', '2005-10-17', 169, 56, '여', '재학', 504);
```

### 03
