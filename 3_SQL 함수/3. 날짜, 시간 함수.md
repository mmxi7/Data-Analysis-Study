# 날짜, 시간 함수

**현재 날짜와 시간을 조회하거나, 날짜/시간 타입의 값을 추출·계산·변환**

<br>

| 함수 | 기능 |
|---|---|
| `NOW()` | 현재 날짜와 시간 반환 |
| `CURDATE()` | 현재 날짜 반환 |
| `CURTIME()` | 현재 시간 반환 |
| `DATE()` | 날짜/시간 값에서 날짜 추출 |
| `TIME()` | 날짜/시간 값에서 시간 추출 |
| `YEAR()` | 연도 추출 |
| `MONTH()` | 월 추출 |
| `DAY()` | 일 추출 |
| `DATE_ADD()` | 날짜에 일정 기간 추가 |
| `DATE_SUB()` | 날짜에서 일정 기간 차감 |
| `DATEDIFF()` | 두 날짜의 차이를 일(day) 단위로 계산 |
| `DATE_FORMAT()` | 날짜를 원하는 문자열 형식으로 변환 |
| `QUARTER()` | 날짜가 속한 분기 반환 |

<br>

### `DATE_FORMAT`의 주요 형식 문자

| 기능 | 형식 문자 | 기능 | 형식 문자 |
|---|---|---|---|
| 달 이름 | `%M` | MM 형식의 월 | `%m` |
| 요일 이름 | `%W` | 24시간제 시간 | `%H` |
| YYYY 형식의 년도 | `%Y` | 24시간제 시간 | `%k` |
| YY 형식의 년도 | `%y` | 12시간제 시간 | `%h` |
| 요일 이름의 약자 | `%a` | MM 형식의 분 | `%i` |
| DD 형식의 날짜 | `%d` | SS 형식의 초 | `%s` |
| D 형식의 날짜 | `%e` | AM/PM | `%p` |

### 01

`professors` 테이블에서 각 교수의 입사일로부터 현재까지 근속 연수(년)를 계산하시오.

```sql
SELECT
    name AS 교수이름,
    hiredate AS 입사일,
    FLOOR(DATEDIFF(CURDATE(), hiredate) / 365) AS 근속 연수
FROM professors
LIMIT 0, 5;
```

### 02

`departments` 테이블에서 설립 연도가 30년 이상 지난 학과명과 설립 연도를 조회하시오.

```sql
SELECT dname AS 학과명, established AS 설립연도
FROM departments
WHERE YEAR(CURDATE()) - established >= 30
ORDER BY established
LIMIT 0, 5;
```

### 03

`students` 테이블에서 생년월일을 `'MM월 DD일'` 형식으로 변환하여 출력하시오.

```sql
SELECT
    name AS 학생이름,
    birthdate AS 생년월일,
    DATE_FORMAT(birthdate, '%m월 %d일') AS 생일_형식
FROM students
ORDER BY birthdate
LIMIT 0, 5;
```

### 04

`enrollments` 테이블에서 수강신청일로부터 30일 후 날짜를 다음 시험일로 가정하고 출력하시오.

```sql
SELECT
  student_id,
  subject_id,
  enroll_date AS 수강신청일,
  DATE_ADD(enroll_date, INTERVAL 30 DAY) AS 시험예정일
FROM enrollments
ORDER BY 시험예정일 DESC
LIMIT 0, 5;
```

### 05

`students` 테이블에서 생년월일을 기준으로 나이가 가장 많은 학생의 이름과 나이(년)를 출력하시오.

```sql
SELECT
    name AS 학생이름,
    birthdate AS 생년월일,
    FLOOR(DATEDIFF(CURDATE(), birthdate) / 365) AS 나이
FROM students
ORDER BY 나이 DESC
LIMIT 0, 1;

또는

SELECT
    name AS 학생이름,
    birthdate AS 생년월일,
    YEAR(CURDATE()) - YEAR(birthdate) + 1 AS 나이
FROM students
ORDER BY 나이 DESC
LIMIT 0, 1;
```
