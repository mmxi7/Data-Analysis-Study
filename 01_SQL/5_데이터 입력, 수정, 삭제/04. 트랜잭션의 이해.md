# 트랜잭션의 이해

### 트랜잭션의 개념

- 하나의 DB에서 하나의 **논리 작업 단위**로 간주되는 일련의 SQL 묶음
SQL 묶음을 실행하는 중간에 오류가 발생하면 **데이터 불일치** 현상 발생

### 트랜잭션의 4대 특성 (ACID)
|특성|의미|설명|
|---|---|---|
|Atomicity (원자성)|All or Nothing|트랜잭션의 모든 완전히 수행되거나 수행되지 않아야 함|
|Consistency (일관성)|Integrity 유지|트랜잭션 전후로 데이터의 무결성이 유지되어야 함|
|Isolation (격리성)|독립 실행|동시에 여러 트랜잭션이 실행되어도 서로 간섭하지 않아야 함|
|Durability (지속성)|영속성|트랜잭션이 성공적으로 완료되면 그 결과는 영구적으로 저장됨|

### 트랜잭션 제어 명령어
- START TRANSACTION;
- COMMIT;
- ROLLBACK;
- SAVEPOINT ();
- ROLLBACK TO ();

### 01

컴퓨터공학과(101) 소속 교수 중, 재직 상태가 `휴직`인 교수의 급여를 10% 인상하되,  
중간에 오류가 발생하면 이전 상태로 되돌릴 수 있도록 트랜잭션을 적용하시오.

```sql
START TRANSACTION;
UPDATE professors SET sal = sal * 1.1 WHERE department_id = 101 AND status = '휴직';
COMMIT;
```

### 02

학생 10106이 수강 중인 모든 과목 점수를 80점으로 일괄 변경하고,  
변경 결과가 이상하면 되돌릴 수 있도록 트랜잭션을 적용하시오.

```sql
START TRANSACTION;
UPDATE enrollments SET score = 80 WHERE student_id = 10106;
ROLLBACK;
```

### 03

트랜잭션을 시작한 후 SAVEPOINT를 사용하여 학생 10102, 10103의 학년을 각각 1씩 올리고,  
10103의 변경만 취소하시오.

```sql
START TRANSACTION;

UPDATE students SET grade = grade + 1 WHERE id = 10102;
SAVEPOINT A;

UPDATE students SET grade = grade +1 WHERE id = 10103;
SELECT id, name, grade FROM students WHERE id IN (10102, 10103);
ROLLBACK TO A;

COMMIT;

SELECT id, name, grade FROM students WHERE id IN (10102, 10103);
```

### 04

트랜잭션을 이용해 교수 9912가 담당 중인 모든 과목의 학점을 1점 증가시키되  
수정 전후 데이터를 비교하여 확인하시오. 하지만 데이터 변경사항이 실제로 저장되어서는 안됩니다.

```sql
START TRANSACTION;
SELECT id, name, credit, professor_id FROM subjects WHERE professor_id = 9912;

UPDATE subjects SET credit = credit + 1 WHERE professor_id = 9912;

SELECT * FROM subjects WHERE professor_id = 9912;
ROLLBACK;
```

### 05

학생 10109이 새 과목(1007)에 수강신청을 추가하려고 한다.  
INSERT와 동시에 학생의 학년을 3으로 수정하는 작업을 하나의 트랜잭션으로 처리하시오.

```sql
START TRANSACTION;

INSERT INTO enrollments (student_id, subject_id, enroll_date) VALUES (10109, 1007, NOW());
SELECT student_id, subject_id, enroll_date FROM enrollments WHERE student_id = 10109;

UPDATE students SET grade = grade + 1 WHERE id = 10109;

COMMIT;
```
