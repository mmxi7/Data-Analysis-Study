# 데이터 입력하기(2)

### 도메인 무결성

각 컬럼은 정해진 형식의 데이터만 저장 가능   

ENUM(A, B, C ...) 타입: 더 강력한 **도메인 무결성** 보장

### 참조키(FOREIGN KEY)

한 테이블의 컬럼이 **다른 테이블의 PK를 참조**  

참조 무결성 유지

테이블 구조에서 `MUL`로 표시됨

### 암호화된 값 저장

- MD5(x):  `x`를 암호화한 값을 저장

### 현재 시각 저장

- NOW()

### 01

students 테이블에 학생을 추가하되, 성별은 '남', 상태는 '재학'으로 저장하세요. 입학일은 오늘 날짜로 저장하며, 키/몸무게는 임의로 설정하세요. 그 밖의 다른 필수 항목은 임의의 데이터로 지정하세요.

```sql
INSERT INTO students (
    name, user_id, grade, birthdate, idnum, height, weight,

)
VALUES (
```


### 03

학생 이름이 '김하늘', 소속 학과명이 '소프트웨어공학과'인 학생을 등록하세요.

이메일은 이름+소속학과앞글자3개@myschool.ac.kr 형식으로 생성하며, 전부 소문자로 저장하면 됩니다.

> 예: kimhn소프트@myschool.ac.kr → kimhn소프트@myschool.ac.kr → 소문자 변환

그 밖의 정보는 임의로 설정하여 저장하세요.

```sql
INSERT INTO students (
```
