## 형변환 함수

| 함수 | 기능 |
|---|---|
| `CAST(expr AS type)` | 값을 지정한 데이터 타입으로 변환 |
| `CONVERT(expr, type)` | `CAST()`와 동일하게 값을 지정한 데이터 타입으로 변환 |

<br>

## 조건 함수

| 함수 | 기능 |
|---|---|
| `IF(조건, 참, 거짓)` | 조건이 참이면 두 번째 값, 거짓이면 세 번째 값 반환 |
| `IFNULL(값, 대체값)` | 값이 `NULL`이면 대체값 반환 |
| `NULLIF(값1, 값2)` | 두 값이 같으면 `NULL`, 다르면 첫 번째 값 반환 |
| `CASE` | 여러 조건을 순서대로 검사하여 결과 반환 |

### 01

학생의 이름(`name`)과 학년(`grade`)을 조회하고, 학년에 따라 다음과 같이 `"구분"`을 표시하는 새로운 컬럼을 만드시오.

- 1학년: 신입생 / 2학년: 재학생 / 3학년: 재학생 / 4학년: 졸업반

```sql
SELECT name, grade,
  CASE
    WHEN grade = 1 THEN '신입생'
    WHEN grade = 4 THEN '졸업반'
    ELSE '재학생'
  END AS 구분
FROM students;
```

### 02

학생의 이름, 키, 키상태를 조회하려고 한다. 키상태는 학생의 키가 170cm 이상이면 `NULL`, 그보다 작으면 `'작음'`이라고 표시하되, 이 결과가 `NULL`일 경우에는 `'경고'`라는 문자열로 대체한 값이다.

```sql
SELECT
    name,
    height,
    IFNULL(IF(height >= 170, NULL, '작음'), '경고') AS 키상태
FROM students
LIMIT 100;
```

### 03

학과 테이블에서 학과명(`dname`)과 설립 연도(`established`)를 조회하시오.
설립 연도는 `'YYYY년'` 형식의 문자열로 변환하여 `'설립연도'`라는 별칭으로 표시하시오.

```sql
SELECT
    dname,
    CONCAT(CAST(established AS CHAR), '년') AS 설립연도
FROM departments;
```

### 04

학생의 이름, 성별, 성별 정보를 조회하려고 한다. 성별 정보는 `남`은 `Male`, `여`은 `Female`, 그 외는 `기타`로 구분하는 값이다. 성별 정보가 입력되지 않은 경우는 `미입력`으로 출력되어야 한다.

```sql
SELECT name, gender,
  IFNULL(
    CASE
      WHEN gender = '남' THEN 'Male'
      WHEN gender = '여' THEN 'Female'
      WHEN gender IS NOT NULL THEN '기타'
    END, '미입력') AS '성별 정보'
FROM students;
```

### 05

학생들의 키와 몸무게를 활용하여 건강 지수를 계산하려고 한다. 키(cm)의 제곱을 몸무게(kg)로 나눈 값을 소수점 둘째 자리까지 반올림하여 `'건강지수'`로 출력하고, 그 값이 350 이상이면 `우수`, 300 이상이면 `양호`, 그보다 작으면 `주의`라고 판단하여 `'건강등급'`으로 함께 표시하시오.

```sql
SELECT
    name,
    height,
    weight, ROUND(POWER(height, 2) / weight, 2) AS 건강지수,
    CASE
      WHEN ROUND(POWER(height, 2) / weight, 2) >= 350 THEN '우수'
      WHEN ROUND(POWER(height, 2) / weight, 2) >= 300 THEN '양호'
      ELSE '주의'
    END AS 건강등급
FROM students;
```
