# 데이터베이스의 구성

### 서버와 클라이언트

- **클라이언트(Client)** : 서버에 요청을 보내는 쪽
- **서버(Server)** : 클라이언트의 요청을 받아 처리하고 응답하는 쪽

<br>

### 데이터베이스의 구조

| Excel | Database |
|---|---|
| Excel 프로그램 | DBMS |
| Excel 문서 | Database |
| Excel 시트 | Table |
| 행(Row) | Record |
| 열(Column) | Field 또는 Column |

**DBMS → Database → Table → Row / Column**

<br>

### 데이터베이스 살펴보기

```sql
-- 데이터베이스 목록 확인
SHOW DATABASES;

-- 사용할 데이터베이스 선택
USE myschool;

-- 테이블 목록 확인
SHOW TABLES;

-- 테이블 데이터 조회
SELECT * FROM departments;

-- 테이블 구조 확인
DESC departments;
```

<br>

### 테이블의 구조

테이블은 **행(Row)**과 **열(Column)**으로 구성된다.

- **행(Row)** : 하나의 데이터 → Record
- **열(Column)** : 데이터의 속성 → Field 또는 Column

#### DESC

```sql
DESC 테이블명;
```

테이블의 구조와 각 컬럼의 정보를 확인 가능

| 항목 | 의미 |
|---|---|
| `Field` | 컬럼 이름 |
| `Type` | 데이터 타입과 크기 |
| `Null` | NULL 허용 여부 |
| `Key` | 키 여부 |
| `Default` | 기본값 |
| `Extra` | 추가 속성 |

#### auto_increment

새로운 데이터가 저장될 때 숫자가 자동으로 1씩 증가하는 속성

<br>

### 데이터 타입

| 데이터 타입 | 설명 |
|---|---|
| `INT` | 정수 |
| `CHAR(n)` | 고정 길이 문자열 |
| `VARCHAR(n)` | 가변 길이 문자열 |
| `DATE` | 날짜 (`YYYY-MM-DD`) |
| `DATETIME` | 날짜와 시간 (`YYYY-MM-DD HH:MM:SS`) |
| `ENUM` | 정해진 값 중 하나를 저장 |
