# 윈도우 함수

**행과 행 간의 관계를 쉽게 정의**하는 함수

<br>

## RANK

특정 열의 값을 기준으로 **순위**를 계산하는 함수

예) 2등이 2명이라면 순위는 `1 2 2 4 5`

### 기본 구문

```sql
SELECT ...
      RANK() OVER (...) AS
FROM;
```

<br>

## DENSE_RANK

순위를 계산하지만 동점자가 있어도 다음 순위를 건너뛰지 않음

예) 2등이 2명이라면 순위는 `1 2 2 3 4`


### 기본 구문

```sql
SELECT ...
       DENSE_RANK() OVER (...) AS 순위
FROM;
```

<br>

## PARTITION BY

데이터를 지정한 기준에 따라 나눈 뒤 **각 그룹 안에서 윈도우 함수를 계산**할 때 사용

### 기본 구문
```sql
SELECT ...
       RANK() OVER (PARTITION BY ... ORDER BY ...) AS ...
FROM;
```

<br>

## 집계 함수

윈도우 함수와 함께 사용할 수 있는 대표적인 집계 함수:
```text
SUM()
AVG()
COUNT()
MAX()
MIN()
```

### 01

`students` 테이블을 사용하여, 각 학년(grade)별로 키(height)가 가장 큰 학생부터 순위를 매겨주세요.  
순위는 `RANK()` 함수를 사용하고, 결과에는 학생의 이름, 학년, 키, 그리고 학년별 키 순위가 포함되어야 합니다.

```sql
SELECT
      name,
      grade,
      height,
      RANK() OVER (PARTITION BY grade ORDER BY height DESC) AS 키순위
FROM students;
```

### 02

`enrollments` 테이블을 사용하여, 과목번호(subject_id)가 1026인 과목의 성적(score) 순위를 매겨주세요.  
성적이 높은 학생이 1등입니다. 순위는 `DENSE_RANK()`를 사용하고, 결과에는 학생 번호, 과목 번호, 성적, 그리고 성적 순위가 포함되어야 합니다.

```sql
SELECT
      student_id,
      subject_id,
      score,
      DENSE_RANK() OVER (ORDER BY score DESC) AS '성적 순위'
FROM enrollments
WHERE subject_id = 1026;
```

### 03

`students` 테이블에서, 각 학과(department_id)별로 학년(grade)이 높은 순서대로 순위를 매겨주세요.  
학년이 같다면, 이름(name)을 기준으로 가나다순(오름차순)으로 정렬합니다. 순위는 `RANK()`를 사용하고, 결과에는 학생 이름, 학과 번호, 학년, 그리고 학과별 학년 순위가 포함되어야 합니다.

```sql
SELECT
      name,
      department_id,
      grade,
      RANK() OVER (PARTITION BY department_id ORDER BY grade DESC, name ASC) AS '학년 순위'
FROM students;
```

### 04

`enrollments` 테이블에서, 모든 과목에 대해 각각의 성적(score) 순위를 매겨주세요.  
성적이 높은 학생이 1등입니다. 순위는 `RANK()`를 사용하고, 동점자는 같은 순위를 부여하며 다음 등수는 건너뜁니다.  
결과에는 학생 번호, 과목 번호, 성적, 그리고 과목별 성적 순위가 포함되어야 합니다.

```sql
SELECT
      student_id,
      subject_id, score,
      RANK() OVER(PARTITION BY subject_id ORDER BY score DESC) AS '성적 순위'
FROM enrollments;
```

### 05

`students` 테이블에서, 성별(gender)로 그룹을 나누고, 각 그룹 내에서 몸무게(weight)가 많이 나가는 순서대로 순위를 매겨주세요. 순위는 `DENSE_RANK()`를 사용합니다.  
결과에는 학생 이름, 성별, 몸무게, 그리고 성별 내 몸무게 순위가 포함되어야 합니다.

```sql
SELECT
      name,
      gender,
      weight,
      DENSE_RANK() OVER (PARTITION BY gender ORDER BY weight DESC) AS '성별 내 몸무게 순위'
FROM students;
```
