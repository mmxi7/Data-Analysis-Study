# 집합 연산자

두 개 이상의 SELECT문의 조회 결과를 **하나의 결과로 결합하거나 비교**할 때 사용

### 정리

| 연산자 | 의미 | 중복 처리 |
|---|---|---|
| `UNION` | 합집합 | 중복 제거 |
| `UNION ALL` | 합집합 | 중복 유지 |
| `INTERSECT` | 교집합 | 공통 데이터 조회 |
| `EXCEPT` | 차집합 | 두 번째 결과에 있는 데이터 제외 |


<details>
<summary><h2>연습문제</h2></summary>

### 01

재직 중인 교수와 재학 중인 학생의 이름(name)을 모두 조회하여 하나의 목록으로 만드시오.  
**(중복된 이름은 한 번만 표시)**

```sql
SELECT name FROM students WHERE status = '재학'
UNION
SELECT name FROM professors WHERE status = '재직';
```

### 02

교수(professors) 테이블에는 있지만 학생(students) 테이블에는 없는 학과 ID를 찾으시오.  
**(즉 교수는 있으나 학생은 없는 학과)**

```sql
SELECT department_id FROM professors
EXCEPT
SELECT department_id FROM students;
```

### 03

키가 180cm 이상인 학생이 소속된 학과와, 2000년 이후에 설립된 학과에 공통적으로 해당하는 학과 ID를 조회하시오.

```sql
SELECT department_id FROM students WHERE height >= 180
INTERSECT
SELECT id FROM departments WHERE established >= 2000;
```

### 04

컴퓨터공학과(학과 ID: 101)에 소속된 학생의 이름과, 직급이 '교수'인 교수의 이름을 합쳐서 조회하시오.  
**(중복 허용)**

```sql
SELECT name FROM students WHERE department_id = 101
UNION ALL
SELECT name FROM professors WHERE position = '교수';
```
