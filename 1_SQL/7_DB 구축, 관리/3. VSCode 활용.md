# IDE의 이해

## 통합 개발 환경 (Integrated Development Environment, IDE)

코딩, 디버그, 컴파일, 배포 등 프로그램 개발에 관련된 모든 작업을 하나의 프로그램 안에서 처리하는 환경을 제공하는 소프트웨어

| 구분 | 설명 |
|---|---|
| **코딩** | 특정한 프로그래밍 언어를 이용해 구체적인 컴퓨터 프로그램을 구현하는 기술 |
| **디버그** | 컴퓨터 프로그램의 정확성이나 논리적인 오류(버그)를 찾아내는 테스트 과정 |
| **컴파일** | 소스코드를 실행 가능한 형태로 변환하는 처리 |
| **배포** | 최종 사용자에게 소프트웨어를 제공하는 과정 |

<br>

## Visual Studio Code 소개

### Visual Studio Code

- Microsoft에서 개발/배포하는 **무료 IDE**
- 현존하는 대부분의 프로그래밍 언어를 Windows와 Mac에서 동일하게 지원하기 때문에 IDE 중에서 가장 인기가 높음
- 수많은 익스텐션(확장팩)을 통해 기능을 확장할 수 있음
  - MariaDB 클라이언트 익스텐션 지원
