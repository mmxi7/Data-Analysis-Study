# 집계 함수

여러 행의 데이터를 하나의 값으로 요약하여 계산할 때 사용
- 집계 함수는 `WHERE` 절에서 사용할 수 없다.

<br>

| 함수 | 기능 | NULL 처리 |
|---|---|---|
| `COUNT(*)` | 전체 행의 개수 | NULL 여부와 관계없이 행 계산 |
| `COUNT(컬럼)` | 해당 컬럼의 값 개수 | NULL 제외 |
| `SUM()` | 합계 | NULL 제외 |
| `AVG()` | 평균 | NULL 제외 |
| `MAX()` | 최댓값 | NULL 제외 |
| `MIN()` | 최솟값 | NULL 제외 |
| `GROUP_CONCAT()` | 여러 값을 문자열로 결합 | NULL 제외 |

### 01

`students` 테이블을 사용하여 현재 4학년인 학생의 총 수와 졸업(`status` = `'졸업'`)한 학생의 총 수를 각각 조회하시오.

```sql
SELECT
    COUNT(CASE WHEN grade = 4 AND status = '재학' THEN id END) AS '4학년 학생 수',
    COUNT(CASE WHEN status = '졸업' THEN id END) AS '졸업생 수'
FROM students
```

### 02

`professors` 테이블에서 직급(`position`)이 `'교수'`인 분들의 급여(`sal`) 총합을 조회하시오.

```sql
SELECT SUM(sal) AS '교수 직급 총 급여'
FROM professors
WHERE position = '교수';
```

### 03

`students` 테이블에서 모든 학생의 키(`height`)에 대한 평균, 최댓값, 최솟값을 각각 조회하시오.
(단, 평균 키는 소수점 둘째 자리에서 반올림하여 첫째 자리까지만 표시하시오.)

```sql
SELECT
    ROUND(AVG(height), 1) AS 평균키,
    MAX(height) AS 최장신,
    MIN(height) AS 최단신
FROM students;
```

### 04

`enrollments` 테이블에서 1002번 과목(`subject_id` = 1002)을 수강한 학생들의 최고 성적(`score`)과 최저 성적을 조회하시오.

```sql
SELECT
    MAX(score) AS '최고 성적',
    MIN(score) AS '최저 성적'
FROM enrollments
WHERE subject_id = 1002;
```

### 05

`departments` 테이블에서 `'인문사회관'`과 `'경영관'`에 위치한 모든 학과(`dname`)의 이름을 콤마로 연결하여 하나의 문자열로 조회하시오.

```sql
SELECT GROUP_CONCAT(dname) AS '학과 목록'
FROM departments
WHERE loc IN ('인문사회관', '경영관');
```
