# 서브쿼리(2)

## FROM절 서브쿼리

- `FROM`절 내부에 `SELECT`문을 작성하여 그 결과를 **임시 테이블처럼 사용하는 방식**
- 서브쿼리의 결과가 많을 경우 전체적으로 느려질 수 있으므로 사용에 주의
- `FROM`절 서브쿼리에는 반드시 **별칭(alias)**을 지정해야 함

### 기본 구문

```sql
SELECT 컬럼명
FROM (
    SELECT 컬럼명
    FROM 테이블명
    WHERE 조건
) AS 별칭;
```

<br>

## 스칼라 서브쿼리

- `SELECT`절에 포함되는 **단일행 서브쿼리**

### 기본 구문

```sql
SELECT 컬럼명,
       (SELECT 단일값
        FROM 테이블명
        WHERE 조건) AS 별칭
FROM 테이블명;
```

> 같은 결과를 얻을 수 있다면 `JOIN`을 사용하는 것이 더 좋음


### 유형

| 구분 | 비상관 서브쿼리 | 상관 서브쿼리 |
|---|---|---|
| 메인쿼리 참조 | 참조하지 않음 | 메인쿼리의 컬럼을 참조 |
| 실행 결과 | 메인쿼리의 각 행에 동일한 결과 사용 | 메인쿼리의 각 행에 따라 결과가 달라질 수 있음 |
| 특징 | 서브쿼리가 독립적으로 실행 가능 | 서브쿼리만 독립적으로 실행하기 어려움 |
| 예시 조건 | `department_id = 101` | `e.student_id = s.id` |
| 의미 | 모든 행에서 같은 값을 조회 | 현재 행의 값을 이용하여 각각 조회 |

### 상관 서브쿼리를 JOIN으로 변경

상관 서브쿼리는 경우에 따라 `JOIN`과 `GROUP BY`로 변경할 수 있다.

```sql
SELECT s.id, s.name,
       (SELECT COUNT(*)
        FROM enrollments e
        WHERE e.student_id = s.id) AS cnt
FROM students s
WHERE s.department_id = 202;
```

```sql
SELECT s.id, s.name, COUNT(e.subject_id) AS cnt
FROM students s
LEFT JOIN enrollments e
    ON e.student_id = s.id
WHERE s.department_id = 202
GROUP BY s.id, s.name;
```

- 수강 내역이 없는 학생도 결과에 포함하려면 `LEFT JOIN` 사용
- `COUNT(e.subject_id)`를 사용하면 수강 내역이 없는 학생은 `0`으로 집계됨
- 같은 목적이라면 일반적으로 서브쿼리보다 `JOIN`이 더 빠를 수 있음

<br>

## 정리

| 구분 | 위치 | 특징 |
|---|---|---|
| FROM절 서브쿼리 | `FROM` | 조회 결과를 임시 테이블처럼 사용 |
| 스칼라 서브쿼리 | `SELECT` | 하나의 값을 컬럼처럼 사용 |
| 비상관 서브쿼리 | 주로 `SELECT` | 메인쿼리를 참조하지 않음 |
| 상관 서브쿼리 | 주로 `SELECT` | 메인쿼리의 현재 행을 참조 |
