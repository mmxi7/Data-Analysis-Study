## WHERE 절

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 검색조건
ORDER BY 정렬기준
LIMIT 시작위치, 개수;
```

### 비교 연산자

| 연산자 | 의미 |
|---|---|
| `=` | 같다 |
| `!=` | 다르다 |
| `<>` | 다르다 |
| `<` | 작다, 미만 |
| `<=` | 작거나 같다, 이하 |
| `>` | 크다, 초과 |
| `>=` | 크거나 같다, 이상 |

### 논리 연산자

여러 개의 검색 조건을 함께 사용할 때 논리 연산자를 사용한다.

| 연산자 | 의미 |
|---|---|
| `AND` | 여러 조건을 모두 만족 |
| `OR` | 하나 이상의 조건을 만족 |
| `NOT` | 조건을 부정 |

### 01

급여가 500만원 이상인 교수들의 교수번호, 이름, 급여를 급여가 높은 순으로 조회하시오.

```sql
SELECT id, name, sal
FROM professors
WHERE sal >= 500
ORDER BY sal DESC;
```

### 02

3학년 여학생 중에서 키가 큰 상위 5명의 이름, 학년, 성별, 키를 키가 큰 순으로 조회하시오.

```sql
SELECT name, grade, gender, height
FROM students
WHERE grade = 3 AND gender = '여'
ORDER BY height DESC
LIMIT 0, 5;
```

### 03

급여가 300만원 이상인 교수 중에서 급여가 낮은 하위 3명의 교수번호, 이름, 급여를 급여가 낮은 순으로 조회하시오.

```sql
SELECT id, name, sal
From professors
WHERE sal >= 300
ORDER BY sal
LIMIT 0, 3;
```

### 04

학점이 2학점이 아니면서 3학점도 아닌 과목의 과목번호, 과목명, 학점을 조회하는 SQL문을 작성하시오.  
단, 과목명 가나다순으로 정렬하시오.

```sql
SELECT id, name, credit
FROM subjects
WHERE credit NOT IN (2, 3)
ORDER BY name ASC;
```

### 05

1학년이 아니면서 키가 180cm 이상인 남학생들의 이름, 학년, 키, 성별을 키가 큰 순으로 조회하시오.

```sql
SELECT name, grade, height, gender
FROM students
WHERE grade != 1 AND height >= 180 AND gender = '남'
ORDER BY height DESC;
```
