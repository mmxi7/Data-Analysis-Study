# 데이터 기본 조회

### SELECT 기본 구조

```sql
SELECT 컬럼명
FROM 테이블명;
```

### 정리

| 문법 | 기능 |
|---|---|
| `SELECT` | 조회할 컬럼 지정 |
| `FROM` | 조회할 테이블 지정 |
| `AS` | 컬럼에 별칭 지정 |
| `ORDER BY` | 조회 결과 정렬 |
| `ASC` | 오름차순 |
| `DESC` | 내림차순 |
| `LIMIT` | 조회 결과의 범위 제한 |

### 01

교수들의 이름(name), 직급(position), 월급에 200을 더한 값을 조회하시오.  
단, 계산된 결과는 `bonus_salary`라는 열 이름으로 나타나야 한다.

```sql
SELECT name, position, sal + 200 AS bonus_salary
FROM professors;
```

### 02

학생들의 이름(name), 성별(gender), 학년(grade)을 학년 내림차순, 이름 오름차순으로 정렬하여 조회하시오.

```sql
SELECT name, gender, grade
FROM students
ORDER BY grade DESC, name ASC;
```

### 03

교수 중에서 급여가 낮은 순으로 상위 3명의 이름(name), 급여(sal), 직급(position)을 조회하시오.

```sql
SELECT name, sal, position
FROM professors
ORDER BY sal ASC
LIMIT 0, 3;
```

### 04

학생들의 이름(name), 성별(gender), 학년(grade)을 조회하되, 열 이름은 각각 `이름`, `성별`, `학년`으로 표시되도록 하시오.

```sql
SELECT name AS 이름, gender AS 성별, grade AS 학년
FROM students;
```

### 05

각 학과의 이름(dname)과 위치(loc)를 포함하여, 설립 연도(established)에서 1900을 뺀 결과를 `연차`로 표시하여 조회하시오.

```sql
SELECT dname, loc, established - 1900 AS 연차
FROM departments;
```
