# 서브쿼리(1)

### 개요

- 다른 SQL문 내부에 중첩되어 사용되는 `SELECT`문
  - 주로 조건 비교, 값 추출, 필터링, 집계 기준 제공 등의 목적으로 사용
  - 괄호 안의 `SELECT`문이 먼저 실행되어 외부 쿼리에 값을 전달함
    - 서브쿼리는 유형에 따라 단일 값 또는 리스트, 테이블 형태로 반환 가능
  - 서브쿼리는 구문은 더 명확하지만 일반적으로 처리 속도가 JOIN보다 느리기 때문에 가급적 JOIN을 사용하는 것이 더 좋다

### 서브쿼리의 유형

| 종류 | 구분 | 설명 |
| --- | --- | --- |
| 중첩 서브쿼리 (WHERE절) | 단일행 | 단일 값을 반환 → 비교연산자와 함께 사용 |
| 중첩 서브쿼리 (WHERE절) | 다중행 | 여러 값을 반환 → IN, NOT IN과 함께 사용 |
| 스칼라 서브쿼리 (SELECT절) |  | SELECT 절에서 사용 |
| 인라인 뷰 (FROM절) |  | 결과를 테이블처럼 사용 → 서브쿼리에 별칭 필요 (결과내 재검색) |
