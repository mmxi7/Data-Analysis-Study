# 변수의 이해

## 변수

* **데이터(data)를 저장하기 위해 프로그램에 의해 이름을 부여 받은 메모리 공간**

  * 파이썬에서는 특정 키워드에 원하는 값을 대입하는 것으로 표현
  * 대입연산자(`=`)를 사용하여 오른쪽에서 명시하는 값을 왼쪽에서 정의한 단어에 대입
* **변수이름 = 값**

<br>

### 1. 자료형(DataType)

| 자료형       | 설명                                        |
| --------- | ----------------------------------------- |
| `None`    | 값이 저장되지 않은 상태로 메모리의 공간만 할당받은 변수(=비어 있는 값) |
| `int`     | 일반 정수                                     |
| `float`   | 소수점을 포함하는 실수                              |
| `bool`    | 논리형. 참(True) 또는 거짓(False) 값               |
| `string`  | 문자열. 문장 형태                                |
| `complex` | 복소수. 실수와 허수부의 합으로 된 숫자로 표현 (거의 사용 안함)     |

<br>

# 변수 이름 규칙

1. 영어, 숫자, 언더바(`_`)의 조합만 사용 가능하고 영어 대소문자를 구분
   * 한글도 가능하지만 권장하지 않음
2. 첫 글자는 숫자를 사용할 수 없음
3. 공백문자(띄어쓰기)를 포함할 수 없음
4. 두 개 이상의 단어를 조합하여 띄어쓰기가 필요한 경우, 언더바(`_`)를 사용하거나 띄어쓰기 위치를 대문자로 표현
   * 예: `hello_world`, `helloWorld`
5. 파이썬에서 사용하는 예약어(키워드)를 사용할 수 없음

<br>

# 예약어

특정한 기능을 갖는 단어

* 변수이름으로 사용할 수 없음   
`False`, `None`, `True`, `and`, `as`, `assert`, `async`, `await`, `break`, `class`, `continue`, `def`, `del`, `elif`, `else`, `except`, `finally`, `for`, `from`, `global`, `if`, `import`, `in`, `is`, `lambda`, `nonlocal`, `not`, `or`, `pass`, `raise`, `return`, `try`, `while`, `with`, `yield`

<br>

# 변수의 사용 제약

## 초기화

* **초기화**: 변수에 최초로 값을 저장
* 초기화되지 않은 변수는 사용할 수 없음
* 초기화되지 않은 변수를 사용하면 `NameError`가 발생

<br>

# 다양한 변수 만들기

## 1. 변수의 초기화

* 변수 만들기

  * 오른쪽에서 왼쪽으로 대입
  * 최초 대입을 초기화라고 함.

<br>

## 2. 저장되어 있는 값의 변경

* 한 번 할당된 변수는 다른 값으로 변경 가능
* 기존의 값이 삭제되고 새로운 값이 저장

<br>

## 3. 소수점을 포함하는 값을 저장하는 변수

* 실수형 변수는 소수점을 포함하는 값을 저장
* 자료형은 `float`

<br>

## 4. 논리형 변수

* 참, 거짓을 표현할 수 있는 변수
* `True`와 `False`의 첫 글자가 대문자인 것에 주의
* 자료형은 `bool`

<br>

## 5. 문자열 변수

* 상대따옴표나 홑따옴표로 감싼 모든 형태의 내용
* 자료형은 문자열(string)

<br>

## 6. 내용이 없는 변수(None)

* 메모리 상에 공간만 점유한 상태로 데이터가 저장되어 있지는 않음
* 추후 프로그램이 동작하는 과정에서 값을 저장하기 위해 미리 메모리 공간만 설정해 놓은 상태
* `None`을 사용
